## 🚀 Áreas de interesse  

- **[Backend](#)**: API com NestJS, Fastify e um pouco de Flask, porém esse ultimo ainda tá em desenvolvimento.  
- **[Analise de Dados](#)**: Transformação e manipulação avançada de DataFrames para importações e exportaçãos em banco de dados SQL, como foco principal o BigQuery.  
- **[Automatização de Processos no Google Sheets](#)**: Utilizar dos vários artifícios que o AppScripts suporta para criação de planilhas.  
- **[Automação de processos onlines](#)**: Selenium + python para automação dos mais diverssos processos, desde web scraping a inserção de dados e/ou arquivos.
- **[Interface gráfica de usuário - GUI](#)**: Interfaces para executáveis python.
- **[Extração de dados de arquivos](#)**: Extração de texto de arquivos com python e a utilização de expressões regulares para extração das informações desejadas.
